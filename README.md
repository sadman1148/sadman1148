### About me

I build cross-platform apps in Flutter and the native code beneath them. I started in native Android at BJIT, moved to Flutter as Mobile Applications Lead at mPower, and now lead 20 developers as Technical Lead at the Bangladesh Army IT Directorate.

- Currently building secure communication, real-time tracking and healthcare systems (names withheld under NDA)
- Comfortable below the Flutter layer with platform channels, Kotlin, Java, Swift and Objective-C
- Based in Dhaka, Bangladesh
